# Programming Quiz

A simple quiz application for practicing programming knowledge.

## Features

- Interactive quiz questions
- Immediate feedback
- Clear, easy-to-use interface
- Progress tracking

## Getting Started

### Prerequisites

Make sure you have the following installed:

- A modern web browser
- A local web server (optional)

### Installation

1. Clone the repository:

   ```bash
   git clone <repository-url>
   ```

2. Navigate to the project directory:

   ```bash
   cd programming
   ```

3. Open `index.html` in your browser, or start a local server:

   ```bash
   python -m http.server 8000
   ```

4. Visit `http://localhost:8000` in your browser.

## Usage

Choose an answer for each question and submit it to check whether it is correct. Continue through the quiz until every question has been answered.
